# مسدودکننده تماس (CallBlocker)

اپ اندروید برای رد خودکار تماس یک یا چند مخاطب انتخاب‌شده.

## امکانات
- انتخاب مخاطب از دفترچه تلفن (چندین بار، هر بار یک نفر) یا وارد کردن دستی شماره
- کلید روشن/خاموش کردن رد تماس
- تطبیق شماره با فرمت‌های مختلف (`0912...`، `+98912...`، `0098912...`)
- نیازی به مجوز خواندن مخاطبین یا دفتر تماس نیست

## ساخت APK با گیت‌هاب
1. یک مخزن جدید در GitHub بسازید و همه فایل‌های این پروژه را در شاخه `main` آپلود کنید.
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا دکمه *Run workflow* را بزنید).
3. پس از پایان (حدود ۳ تا ۵ دقیقه) در انتهای صفحه اجرا، بخش **Artifacts** فایل `CallBlocker-APK` را دانلود کنید.
4. فایل را از حالت zip درآورید و `app-debug.apk` را روی گوشی نصب کنید.

## اولین اجرا روی گوشی
- اپ را باز کنید و روی **فعال‌سازی** بزنید، سپس در پنجره سیستم، اپ را به‌عنوان «برنامه فیلتر تماس» تأیید کنید.
- مخاطبین موردنظر را اضافه کنید.

## محدودیت مهم
اپ تماس را رد می‌کند و تماس‌گیرنده بوق «مشغول/رد شده» می‌شنود. پیام «مشترک مورد نظر در دسترس نمی‌باشد» را فقط شبکه اپراتور پخش می‌کند و اپ نمی‌تواند آن را برای شماره‌های خاص پخش کند.

حداقل نسخه اندروید: ۱۰ (API 29).
